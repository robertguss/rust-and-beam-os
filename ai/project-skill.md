# Project context for coding agents

Before work, read `AGENTS.md`, `docs/plan/README.md`, and
`docs/plan/execution-policy.md`; run the plan check and ready query. Work only
on a returned task or an already-owned `in_progress` task.

Only Phase 0 evidence work is authorized. Keep kernel code blocked until Gate 0
has a human-approved decision. Preserve the own-kernel hypothesis and explicit
non-goals in `docs/invariants.md`. Verification and durable evidence are part of
the implementation, not follow-up work.
